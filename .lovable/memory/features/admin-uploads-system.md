---
name: admin-uploads-system
description: Admin tab to upload/list/delete images and PDFs to /api/uploads/{domain}/{section}/ with public URLs, used by Eventos/Avisos/Convocatoria/Reglas pages with build-time fallback
type: feature
---
El admin (`/admin` → tab "Archivos") permite subir, listar y eliminar archivos directamente al servidor IONOS sin re-deploy. Endpoint PHP: `server/api/uploads.php` con `?section=eventos|avisos|convocatoria|reglas|pdfs` y `?action=upload|delete` (POST). Auth: misma password `admin2025`. Archivos se guardan en `/api/uploads/{domain}/{section}/{filename}` (scope por Host header → multi-tenant). Validaciones: extensión + MIME por sección, máx 15MB, sanitización de nombres. Las páginas públicas (`AtraccionesSection`, `AvisosPostersSection`) priorizan los archivos del servidor (`useUploadsList`) sobre los assets de build-time (`posterAssets.ts`); si el servidor está vacío, caen al fallback de `src/assets/{section}/`. Para los PDFs, `Convocatoria.tsx` y `Reglas.tsx` buscan `convocatoria-torneo.pdf` y `reglas-y-cc.pdf` en `pdfs/` y usan esa URL si existe; si no, caen a `/convocatoria-torneo.pdf` y `/reglas-y-cc.pdf` en public/. El componente `AdminUploads` tiene 5 sub-tabs (Eventos, Avisos, Convocatoria, Reglas, PDFs) con grid de miniaturas para imágenes y lista para PDFs, con confirmación AlertDialog antes de borrar. Hooks: `useUploadsList`, `useUploadFiles`, `useDeleteFile` en `src/hooks/useUploads.ts`. El `.htaccess` ya exenta `/api/` del SPA routing, así que las URLs `/api/uploads/...` se sirven como estáticos. Despliegue: subir `server/api/uploads.php` a IONOS (la carpeta `uploads/` se crea sola al primer upload con permisos 0775).
